# my_first_app

## Project Overview
This project is built with Flutter, focusing on setting up the development environment,and managing simple UI layouts and debugging tools.

## What I Learned & Challenges Faced
During this Flutter lab, I learned how to customize user interfaces, and use `MediaQuery` with `debugPrint` to log screen dimensions. The main challenges I faced involved configuring the environment, dealing with Android Studio virtual device setups, and resolving toolchain hurdles. Through iterative troubleshooting and running `flutter doctor`, I successfully overcame these setup blocks and completed the project.
